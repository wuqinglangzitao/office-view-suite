## 比较口径

## 复现与证据

先安装依赖、构建 WASM 与 SDK，再执行：

```sh
pnpm test:packages
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs pnpm test:visual
```

本地结果位于 `output/playwright/visual-regression/results.json`，截图后缀分别为 `-baseline.png` 和 `-sdk.png`；该目录为忽略的验证产物，不随仓库提交。9 组 Word 缩放及渐进分页检查通过，浏览器异常与请求失败均为 0。

另有验证工具问题 **VERIFY-001**：截图名称只使用不含扩展名的样例名，`rich.docx` 与 `rich.xlsx` 的 `rich-001-*.png` 会相互覆盖。JSON 中的即时像素比较仍分别有效，但检查截图时必须区分格式。本次已将 Word 截图另存到 `output/playwright/visual-regression/details/word-rich-001-*.png`；后续应给截图名称增加格式前缀，再生成永久基线。
